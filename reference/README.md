# 参考資料

このフォルダには、外部サービス（Google Apps Script等）で使用するコードの参考用コピーが格納されています。

## Google Apps Script

### gas-messages.js
メッセージ取得用のGoogle Apps Scriptコード

**スプレッドシート構造:**
- B列: メッセージ（必須）
- C列: 名前
- D列: XID

**機能:**
- ページネーション対応（limit, offsetパラメータ）
- レート制限（1分間に60リクエストまで）
- total件数とhasMoreフラグの返却

**使用箇所:** メッセージページ（ページネーション方式）

---

### gas-illusts.js
イラスト取得用のGoogle Apps Scriptコード

**スプレッドシート構造:**
- B列: イラスト画像URL（必須）
- C列: XID
- D列: 名前

**機能:**
- ページネーション対応（limit, offsetパラメータ）
- レート制限（1分間に30リクエストまで）
- total件数とhasMoreフラグの返却

**使用箇所:** イラストページ（無限スクロール方式）

---

## デプロイ手順

1. Google Apps Scriptのエディタを開く
2. 該当するファイルの内容をコピー
3. スプレッドシートIDを設定（コード内の`'XXX'`の部分）
4. デプロイ → 新しいデプロイ → ウェブアプリ
5. デプロイしたURLを `.env.local` に設定
   - `GOOGLE_APPS_SCRIPT_MESSAGES_URL=...`
   - `GOOGLE_APPS_SCRIPT_ILLUSTS_URL=...`

## スケーラビリティと攻撃対策

### 多層防御アーキテクチャ

```
ユーザー
  ↓
[ブラウザキャッシュ 10分] ← useFetch.ts
  ↓
[Vercel Edge Cache 10分] ← API Routes (revalidate = 600)
  ↓
[GAS 同時実行30制限] ← 自然な制限
```

### 同接の限界

| 人数 | 状態 | 説明 |
|------|------|------|
| **〜10,000人** | ✅ 問題なし | Vercel Edge Cacheが効く |
| **10,000〜50,000人** | ⚠️ 遅延発生 | 初回アクセス時に待ち時間 |
| **50,000人〜** | ❌ 追加対策必要 | Cloudflare、GAS複数化を検討 |

**計算根拠:**
- Vercel Edge Cache（10分）で99%のリクエストを吸収
- GAS到達は初回アクセスの1%のみ
- 10,000人 × 1% = 100リクエスト → GAS同時30で順次処理可能

### 悪意のあるアクセス対策

| 攻撃タイプ | 対策 | 効果 |
|-----------|------|------|
| 大量スクレイピング | Vercel Cache + GAS制限 | ✅ 自動で遅延 |
| パラメータ攻撃 | パラメータごとにキャッシュ | ✅ 2回目以降無効化 |
| DDoS | Vercel DDoS Protection | ✅ CDNで吸収 |

### 追加対策（必要時）

- **Cloudflare**（無料） - 50,000人以上の同接対策
- **GAS複数デプロイ** - ラウンドロビンで負荷分散
- **Vercel Pro** - より強力なDDoS対策
